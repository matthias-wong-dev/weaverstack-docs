# Core concepts

Core concepts explain the mental model needed to understand and operate Weaver. They describe public behaviour and its consequences, not the internal arrangement of the source code.

The model begins with [How Weaver works](how-weaver-works.md):

```text
Project declarations
        ↓
Physical bindings
        ↓
Build
        ↓
Load / Test
        ↓
Operational state
        ↓
Health
```

The same model includes projects and estates, logical and physical items, resources and artefacts, dependencies, the catalogue, workflows, fault tolerance, local and Fabric execution, and mirrors.
