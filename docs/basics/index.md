# Basics

Author the items the project needs, add validations beside them, choose the workspace configuration, then use one operating flow across the estate.

## Author the items

- [Build a Lakehouse pipeline with Python](lakehouse-python.md) — load files and Delta Tables, with imports expressing dependencies.
- [Build a Lakehouse pipeline with Spark SQL](lakehouse-spark-sql.md) — use SQL Table and View definitions.
- [Build a Warehouse pipeline](warehouse-pipeline.md) — keep transformations in T-SQL.
- [Deploy semantic models and Reports](power-bi/deploy-pbip.md) — start with native TMDL, then add overlays, annotations or managed sources where useful.

## Validate and configure

- [Add Tests and Assumptions](tests-and-assumptions.md) — validate Lakehouse and Warehouse data and semantic-model DAX through the same Test operation.
- [Connect data with Shortcuts](shortcuts.md) — use managed or externally owned data.
- [Configure a workspace and Python runtime](workspace-and-python-runtime.md) — map items, including models and Reports, to development or production; configure a hosted runtime for the work that needs it.

## Develop and operate

- [Work in Sessions and workflows](sessions-and-workflows.md) — compose ordinary operations in one execution context.
- [The development cycle](development-cycle.md) — edit, preview, Build, load changed work, validate and inspect Health.

- [Troubleshoot a run](troubleshooting.md) or [recover failed work](recover-failed-work.md) from the state left behind.
