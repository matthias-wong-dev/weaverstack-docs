# Start here

Install Weaver, choose your Fabric workspace and start with the item you already know. You do not need to build a whole estate first.

1. [Install the documented snapshot](installation.md) and configure access for the operation you need.
2. Choose [Lakehouse](../lakehouse/python.md), [Warehouse](../warehouse/first-project.md), [Semantic models](../semantic-models/native-tmdl.md) or [Reports](../reports/deploy.md).

For a small optional introduction, [Your first Fabric project](first-project.md) uses Warehouse SQL. The other item routes provide their own starting context; this is not a prerequisite for them.

Once items are working, [Coordinate your estate](../estate/index.md) shows how to connect them and inspect their results together.
