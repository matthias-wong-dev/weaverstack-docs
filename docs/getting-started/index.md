# Start here

Install Weaver and start with the item you already know. You do not need to build a whole estate first.

You can start with Semantic Models and Reports in an existing, suitably licensed Power BI service workspace without setting up a Fabric Warehouse or Lakehouse. Fabric data workloads have their own capacity requirements; see the [two Power BI operating modes](../semantic-models/index.md#two-ways-to-use-weaver-with-power-bi).

1. [Install Weaver](installation.md) and configure access for the operation you need.
2. Choose [Lakehouse](../lakehouse/python.md), [Warehouse](../warehouse/first-project.md), [Semantic models](../semantic-models/native-tmdl.md) or [Reports](../reports/deploy.md).

For a small optional introduction, [Your first Fabric project](../warehouse/first-project.md) uses Warehouse SQL. The other item routes provide their own starting context; this is not a prerequisite for them.

Once items are working, [Coordinate your estate](../estate/index.md) shows how to connect them and inspect their results together.
